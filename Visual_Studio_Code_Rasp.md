# Como instalar y entrar a visual studio code en una Raspbery

## como isntala visual Studio Code
1. Actualiza la lista de paquetes: `sudo apt update`
2. Instala VS Code: `sudo apt install code`
3. Ábrelo desde el menú Programación, luego Visual Studio Code, o con: `code`
